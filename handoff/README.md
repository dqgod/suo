## 维护规则

1. 开始平台相关工作前先读根目录 `AGENTS.md`，再读本文件和目标平台文件。
2. 项目状态只能标记为“待验证”“阻塞”或“已完成”；完成后勾选并记录命令/真实场景，不保留含糊的过期待办。
3. 阻塞项必须保留完整命令、退出码、stderr、系统版本、架构和必要截图。
4. 配置迁移测试必须先备份真实 `config.json` 与 `.bak`，结束后验证原始文件或预期迁移结果，禁止把测试值留给用户。
5. 不在本目录保存密钥、token、代理凭据、用户查询内容或构建产物。
6. `README.md` 只维护状态索引；细节放入对应平台文件，避免重新把阶段日志堆回 `AGENTS.md`。

## 完成交接的判定

一次平台交接只有在以下条件同时满足时才算完成：

- 当前分支和远端状态明确；
- 依赖、前端、Rust 测试和目标平台原生构建通过；
- 受影响的真实应用行为在对应硬件上验证；
- 配置和用户数据已恢复或完成可审计迁移；
- 本目录的状态与主 `README.md` 不冲突。
