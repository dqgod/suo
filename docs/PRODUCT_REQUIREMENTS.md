# Suo Launcher 产品需求与技术方案

> 文档版本：v1.1
> 产品名称：Suo / 梭
> 目标平台：macOS 13+、Windows 10 22H2+ / Windows 11
> 产品定位：一个轻量、键盘优先、可安全扩展的本地快捷启动器

## 1. 产品概述

Suo 的核心不是“把所有功能塞进一个搜索框”，而是建立一个统一的命令入口：用户通过全局快捷键唤起窗口，输入自然查询、算式或命令，在一到两次键盘操作内完成目标。

首个版本聚焦八项能力：

1. 全局快捷键唤起；
2. 搜索并打开应用；
3. 搜索并打开本地文件；
4. 即时计算；
5. 关键词触发翻译；
6. 自定义关键词并运行 Python、Shell/Bash、PowerShell 等脚本；
7. 自定义关键词与 URL 模板，快速发起网络搜索；
8. 自定义主题皮肤。

设计参考来自 Alfred 与 Wox 的成熟交互，但产品范围保持克制：先做好本地启动、搜索和个人命令，不在 MVP 中建设插件市场、AI 对话、剪贴板历史或复杂工作流画布。

## 2. 产品目标与非目标

### 2.1 产品目标

- 用户能够只用键盘完成“唤起 → 输入 → 选择 → 执行”；
- 热启动后窗口在 100 ms 内可见，输入过程无明显卡顿；
- 普通应用查询和已建立索引的文件查询，P95 首屏结果在 200 ms 内出现；
- 计算器在本地完成，不依赖网络；
- 命令别名、解释器、脚本、参数与输出格式均可配置；
- 网络搜索关键词与 URL 模板可配置，并在显式确认后交给默认浏览器；
- macOS 与 Windows 保持相同的命令语法和核心 UI，只在系统能力上使用平台适配器；
- 脚本执行默认遵循最小权限、参数隔离、超时终止与可审计原则；
- 主题可以实时预览、导入和导出。

以上性能数值是设计目标，需在真实安装包和常见硬件上建立基准测试后确认。

### 2.2 MVP 非目标

- Linux 支持；
- 第三方插件商店、在线主题商店；
- 云端账号和跨设备同步；
- 通用 AI 对话；
- 文件内容全文检索；
- 可视化工作流编排器；
- 允许未经确认下载并执行远程脚本；
- 以管理员/root 权限执行脚本。

## 3. 目标用户与典型场景

### 3.1 目标用户

- 频繁切换应用和文件的办公用户；
- 需要运行小工具脚本的开发者与高级用户；
- 希望替代系统搜索，但不需要复杂自动化平台的用户。

### 3.2 核心用户故事

- 作为用户，我按下默认的 `Command + Space` 或 `Alt + Space` 后，可以立即输入应用名并打开它，也可以在通用设置中录制自己的组合键；
- 作为用户，我可以看到当前配置文件的完整路径、打开所在文件夹，并把普通配置安全迁移到自选目录；
- 作为用户，我输入文件名的一部分，可以看到按相关度排序的文件，回车用默认应用打开；
- 作为用户，我输入 `11+1`，可以立即看到 `12`，回车复制结果；
- 作为用户，我输入 `fy hello`，可以看到“你好”，回车复制翻译；
- 作为用户，我可以把 `ts` 绑定到 `timestamp.py`，输入时间戳后看到格式化时间；
- 作为用户，我可以把 `google` 绑定到 Google 查询 URL，输入 `google codex` 后按回车直接在默认浏览器打开结果页；
- 作为用户，我可以给脚本命令和网络搜索选择自己的本地图标，并自定义只输入关键词时显示的提示语；
- 作为高级用户，我可以显式把某条可信脚本的返回文本设为待执行 Shell 命令，并在二次确认动作后打开文件或完成其他本地操作；
- 作为用户，我可以把 `mydoc` 绑定到不含查询占位符的固定文档 URL，只输入 `mydoc` 并回车就直接打开该页面；
- 作为用户，我可以修改 `fy` 为自己习惯的别名，并在冲突时收到提示；
- 作为用户，我可以选择主题、修改颜色和圆角，并即时预览效果。

## 4. 统一交互模型

### 4.1 唤起与关闭

| 平台 | 默认快捷键 | 说明 |
| --- | --- | --- |
| macOS | `Command + Space` | 可能与 Spotlight 冲突，首次启动必须检测并引导用户修改系统或 Suo 快捷键 |
| Windows | `Alt + Space` | 可能覆盖当前窗口系统菜单，可在通用设置中录制其他组合键 |

行为规则：

- Windows 与 macOS 均启用应用级单实例保护；正常运行时再次启动应用会退出新进程，并唤醒、定位已有主窗口；
- 通用设置提供快捷键录制按钮；组合键必须包含 `Command`、`Ctrl`、`Alt` 或 Windows 键。保存时先验证并注册新组合，若按键无效、被占用或配置保存失败，继续保留或恢复原快捷键；
- Suo 运行期间常驻系统托盘；左键唤醒主窗口，右键菜单提供“显示 Suo”“设置”和“退出”；macOS 使用随菜单栏明暗自动反色的单色中空模板图标。“打开设置时显示 Dock 图标”默认开启：只在设置窗口打开期间显示，设置关闭后自动隐藏；关闭该项时始终不显示 Dock 图标，且在设置窗口内实时关闭开关不得使设置窗口退出或隐藏。Windows 保留彩色托盘/应用图标，快捷键搜索窗口不显示任务栏入口，设置窗口显示任务栏入口；
- macOS 搜索窗口必须是可接收键盘输入的非激活面板：从其他应用唤起时不得把前台应用或菜单栏切换为 Suo，原应用输入框的焦点显示应继续保留；显式打开设置窗口时则必须激活 Suo 并显示 Suo 菜单栏。Windows 继续使用普通聚焦窗口；
- 快捷键按下时默认在“当前活跃屏幕”居中偏上位置显示窗口；通用设置可调整启动器宽度 560–1200 px、高度 320–720 px，并相对默认位置做水平 -400–400 px、垂直 -240–240 px 微调；最终位置必须夹紧在目标显示器工作区内；进程首次显示窗口前必须由原生层应用持久化尺寸、空查询紧凑高度和位置，不能先显示 Tauri 默认居中窗口再由前端首帧移动；
- 再次按下快捷键或按 `Esc` 隐藏窗口；macOS 上即使设置窗口仍在后台可见，搜索面板的显示和隐藏也不得激活 Suo 或把设置窗口自动顶到前台；
- 默认在失去焦点时立即隐藏并清空查询；
- 设置中可分别开启“保留上次输入”和“失去焦点时保持窗口”；
- 设置中可开启“空输入时仅显示搜索框”，默认关闭；开启后空查询时收起状态、结果与底栏，输入任意字符后立即恢复完整窗口，清空后再次收起；
- 通用设置可分别配置空输入与非空输入的尾沿防抖，范围均为 0–60000 ms，默认分别为 0 ms 和 50 ms；0 表示立即执行，即时脚本仍使用每条脚本自己的 20–60000 ms 延迟；
- 打开应用、文件或网页后默认关闭，`Shift + Enter` 执行后保持窗口；复制计算、翻译或脚本结果后默认保持窗口。

### 4.2 输入语法

Suo 将输入分为两类：

```text
普通查询：<query>
命令查询：<keyword> [arg1] [arg2] ...
```

解析优先级：

1. 精确匹配已启用的命令关键词；
2. 检测是否为合法算式；
3. 搜索应用；
4. 搜索文件；
5. 无本地结果时显示可配置的回退动作。

命令关键词必须完整匹配首个 token。例如 `fy hello` 命中 `fy`，但 `fyi` 不命中。参数支持引号：

```text
ts 1786082576069
mycmd "hello world" --format json
```

### 4.3 结果列表

每条结果包含：

- 图标；
- 主标题；
- 副标题或路径；
- 来源类型标签；
- 主操作；
- 可选次操作。

图标规则：

- 已发现的应用展示系统原生应用图标；图标只从启动时动态发现的本机应用路径集合读取，并使用并发限制和内存缓存；
- 目录统一展示 Suo 的文件夹图标；
- 除应用以外的普通文件统一展示 Suo 的默认文件图标；
- 原生图标读取失败时回退对应类型的统一图标，不阻塞结果展示。

键盘规则：

| 按键 | 行为 |
| --- | --- |
| `↑` / `↓` | 切换选中项 |
| `Enter` | 执行主操作 |
| `Command/Ctrl + Enter` | 执行次操作，例如“在 Finder/资源管理器中显示” |
| `Command/Ctrl + C` | 复制选中结果的值或路径 |
| `Tab` | 展开结果动作 |
| `Esc` | 清空或关闭 |

## 5. 功能需求

### 5.1 应用搜索与打开（P0）

系统需要发现并索引以下来源：

- macOS：`/Applications`、`~/Applications`、系统应用以及 LaunchServices 可识别应用；
- Windows：开始菜单快捷方式、已注册应用、常见安装位置与 UWP/MSIX 应用；
- 用户额外配置的应用目录。

匹配字段包括应用显示名、文件名、可执行文件名、用户别名。排序综合：

```text
score = 文本匹配度 × 0.55 + 使用频率 × 0.25 + 最近使用 × 0.15 + 类型偏好 × 0.05
```

要求：

- 支持前缀、子串、轻量模糊匹配、拼音全拼和拼音首字母；
- 应用结果优先于同名普通文件；
- 缓存应用图标，避免列表滚动时反复读取；
- 每次 Suo 启动时快速扫描应用来源，设置页提供“立即刷新应用”。

### 5.2 文件搜索与打开（P0）

MVP 仅搜索文件名、扩展名和路径，不搜索文件正文。

普通查询的默认范围：

- 用户主目录下的 Desktop、Documents、Downloads；
- 用户主动添加的目录；
- 默认排除系统目录、隐藏缓存、依赖目录和版本控制内部文件；
- 使用可自定义的 `f <关键词>` 命令时，Everything/Spotlight 可搜索全盘索引。

默认排除示例：

```text
.git, node_modules, Library/Caches, AppData/Local/Temp, $Recycle.Bin
```

平台策略：

- Windows 优先连接用户已经运行的 Everything；安装版在缺少 Everything 时可经用户确认启用 Suo 内置的独立 Everything 实例和 Service；
- Windows 便携版不安装 Service，只连接已有 Everything，否则回退；
- macOS 使用 Metadata/Spotlight，只有用户添加受保护目录时才引导请求相应权限；
- Everything/Spotlight 不可用时，使用 Suo 自有“限定目录索引”作为回退；
- 自有索引使用 SQLite FTS5 保存规范化名称、路径、类型和修改时间。首次启动后台建立索引，此后首版只由用户手动重建，不监听文件变化；
- 网络盘、移动盘默认不建立索引，用户可显式开启。

文件结果主操作为“用默认应用打开”，次操作包括“显示所在位置”“复制路径”。索引设置必须展示目录、排除规则、最近扫描时间、文件数与当前状态。

### 5.3 计算器（P0）

触发条件：输入可被完整解析为合法数学表达式，不能只因为包含数字或运算符就触发。

MVP 支持：

- `+ - * / % ^`；
- 括号和一元正负号；
- 小数；
- `sqrt`、`abs`、`round`、`sin`、`cos`、`tan`；
- 常量 `pi`、`e`。

示例：

| 输入 | 显示 | Enter 行为 |
| --- | --- | --- |
| `11+1` | `12` | 复制 `12` |
| `(2+3)*4` | `20` | 复制 `20` |
| `sqrt(81)` | `9` | 复制 `9` |

禁止使用 JavaScript `eval` 或系统 shell 求值。应使用确定性的表达式解析器，并限制表达式长度与计算复杂度。

### 5.4 翻译命令（P0）

默认命令：

```text
fy <text>
```

`fy` 是唯一的内置翻译命令，用户可为它选择 Microsoft Translator、Google Cloud Translation Basic 或有道智云文本翻译；切换 Provider 不新增或改变命令关键词。默认行为是自动识别源语言；中文输入默认翻译为英文，其他语言默认翻译为简体中文，并支持 `fy:ja hello` 一类临时目标语言语法。常用简繁中文语言代码由适配层转换为当前 Provider 所需格式。用户可配置：

- 命令关键词，例如 `fy`、`tr`；
- 可选描述或使用说明，用于设置页摘要展示；
- 翻译服务提供方；
- 源语言和目标语言；
- Provider 对应凭据：Microsoft 的 Azure Key 与可选 Region、Google Cloud API Key、有道应用 ID 与应用密钥；秘密值写入系统钥匙串/凭据管理器，不写入普通配置文件；
- 超时时间；
- Enter 后复制结果或替换当前输入。

体验要求：

- 默认遵循通用“非空输入防抖”并在停顿 50 ms 后请求；用户可在 0–60000 ms 内调整，输入继续变化时取消尚未执行的任务，并丢弃已发出但过期的结果；
- 显示“翻译中…”、超时、无网络、鉴权失败和额度不足等明确状态；
- 同一文本、语种和提供方的结果默认只在进程内存中缓存；用户可主动开启带容量和期限限制的持久缓存；
- 结果区标明翻译提供方；
- 未配置服务时，输入 `fy` 应直接展示配置入口，而不是静默失败。
- 三家凭据按 Provider 独立保存；切换 Provider 不删除其他凭据，删除操作只影响当前指定 Provider。

### 5.5 自定义命令与脚本（P0）

#### 5.5.1 命令配置

每条命令至少包含：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 不变的唯一 ID |
| `name` | 是 | 展示名称 |
| `keyword` | 是 | 唯一触发词，如 `ts` |
| `description` | 否 | 最多 200 个字符的用途说明或调用示例 |
| `iconDataUrl` | 否 | 用户选择的本地 PNG/JPEG/WebP 图标；最大 256 KB，宽高均不超过 512 px |
| `inputHint` | 否 | 最多 160 个字符；Enter 执行脚本只输入关键词时替代脚本路径作为结果副标题，不声明参数必填 |
| `aliases` | 否 | 命令别名；主关键词和别名在不区分大小写的全局命名空间中唯一 |
| `runtime` | 是 | `python`、`bash`、`shell`、`powershell`、`executable` |
| `scriptPath` | 是 | 脚本或可执行文件绝对路径 |
| `resultAction` | 是 | `copy`（默认）或显式高风险的 `executeShell` |
| `argumentMode` | 是 | `argv` 或原始字符串；默认 `argv` 并支持引号，均不执行 Shell 展开 |
| `argumentRule` | 否 | 后续可用于参数提示/校验；当前 MVP 不声明参数 Schema，参数数量与含义由脚本决定 |
| `executionMode` | 是 | `immediate` 或 `enter`；即时查询默认取消旧任务，也可配置为排队 |
| `debounceMs` | 即时执行时 | 输入停止后等待多久执行；默认 50，范围 20–60000 |
| `workingDirectory` | 否 | 默认脚本所在目录 |
| `timeoutMs` | 是 | 默认 5000，范围 100–60000 |
| `outputFormat` | 是 | `text` 或 `suo-json-v1` |
| `primaryAction` | 是 | `copy`、`open`、`replace-query`、`none` |
| `enabled` | 是 | 是否启用 |

设置页的脚本路径字段必须提供“在文件夹中显示”操作。Suo 应按执行脚本时的同一规则解析绝对路径、`~`、配置目录相对路径和 bundle 资源路径，再调用系统文件管理器打开所在目录并选中脚本；路径必须作为独立参数传递，不得拼接为 shell 字符串。

建议配置示例：

```json
{
  "id": "timestamp-converter",
  "name": "时间戳转换",
  "keyword": "ts",
  "runtime": "python",
  "interpreterPath": "python3",
  "scriptPath": "~/Suo/scripts/timestamp.py",
  "argumentMode": "argv",
  "executionMode": "immediate",
  "debounceMs": 50,
  "workingDirectory": "~/Suo/scripts",
  "timeoutMs": 3000,
  "outputFormat": "text",
  "primaryAction": "copy",
  "enabled": true
}
```

用户输入：

```text
ts 1786082576069
ts 1786082576069 +8
```

进程实际接收的参数应等价于：

```text
python3 timestamp.py 1786082576069
python3 timestamp.py 1786082576069 +8
```

标准输出：

```text
2026-08-07 14:02:56
```

Suo 只负责将命令后的文本安全拆分为独立 argv；参数数量、顺序、可选性和含义均由脚本自身决定。示例脚本把第一个参数解释为毫秒时间戳，把可选的第二个参数解释为 `+8`、`-5` 或 `+08:30` 形式的时区偏移。启动器将首个非空文本结果显示为主标题；`copy` 在再次回车时复制，`executeShell` 则在再次回车或点击时执行返回文本。后者不得因即时脚本、搜索建议或预览而自动执行。

`executeShell` 是逐脚本显式开启的高风险能力：macOS 固定通过 `/bin/bash -lc`，Windows 固定通过非交互 PowerShell `-Command` 执行。WebView 只能收到一次性不透明 action ID，不得收到或自行构造原始 Shell 动作；后端必须在当前查询 epoch 内缓存命令、二次校验脚本仍启用且动作类型未改变，并在首次激活、查询变化、取消或配置变化后销毁授权。空返回、NUL 和超过 16 KiB 的命令不可执行；执行继续服从 100–60000 ms 超时、1 MB 输出上限、非 root/非管理员限制和平台进程树终止。

#### 5.5.2 结构化输出

复杂脚本可输出一行 JSON：

```json
{
  "version": 1,
  "items": [
    {
      "title": "2026-08-07 14:02:56",
      "subtitle": "Asia/Hong_Kong · 毫秒时间戳",
      "value": "2026-08-07 14:02:56",
      "action": "copy"
    }
  ]
}
```

解析失败时显示“脚本输出格式错误”，并允许用户从诊断页复制 stdout/stderr，但不得把异常栈直接塞进主结果列表。

#### 5.5.3 执行与安全边界

- 默认使用参数数组启动进程，不把整段输入拼接成 shell 字符串；
- `argv` 模式下禁止 shell expansion、命令替换、管道与重定向；
- 只有用户显式选择“Shell 表达式模式”时才交给 shell，并持续显示高风险标识；
- 首次运行新脚本前展示解释器、脚本路径、工作目录与权限确认；Shell 高级模式下脚本内容变化后重新确认；
- 不继承全部父进程环境变量，只传递系统必要变量和用户明确允许的变量；
- API Key 等密钥使用系统安全存储，并以命令级授权注入；
- stdout、stderr 默认各限制 1 MB，允许在安全范围内按命令调整，全局硬上限 10 MB；
- 纯文本默认先按 UTF-8 解码，失败后尝试系统编码，并允许按命令指定；`suo-json-v1` 强制 UTF-8；
- 超时后先请求正常终止，短暂等待后强制终止整个进程树；
- 禁止通过 UI 配置管理员/root 提权；
- 保存最近运行状态、耗时和退出码，但默认不保存可能包含敏感信息的完整参数与输出；
- 窗口关闭时默认终止所有脚本；动作命令可配置为后台继续，并按命令设置完成/失败通知；
- 脚本路径指向新文件时重新确认；普通模式下原文件内容变化直接生效。

### 5.6 自定义网络搜索（P0）

用户可以将关键词映射到 HTTP/HTTPS URL。URL 可以带 `{query}` 或位置参数占位符，也可以是不含占位符的固定直达链接。

Google 搜索配置示例：

```json
{
  "id": "google-search",
  "name": "Google 搜索",
  "keyword": "google",
  "urlTemplate": "https://www.google.com.hk/search?q={query}",
  "openMode": "default-browser",
  "argumentRequired": true,
  "enabled": true
}
```

用户输入：

```text
google codex
```

启动器首先显示一条可执行结果：

```text
使用 Google 搜索“codex”
https://www.google.com.hk/search?q=codex
```

用户按 `Enter` 后，Suo 调用系统默认浏览器打开该 URL。不能在用户仍在输入时自动弹出浏览器。

固定链接配置示例：关键词 `mydoc` 对应 `https://bytedance.feishu.cn/drive/home/`。输入 `mydoc` 时直接生成“打开”结果，按 `Enter` 后打开该固定页面，不要求额外参数。

需求与约束：

- 关键词必须唯一，并与翻译、脚本和其他内置命令共用冲突检测；
- 每条网络搜索可配置最多 200 个字符的描述或使用说明；
- 每条网络搜索可选一个本地 PNG/JPEG/WebP 图标，并可配置最多 160 个字符的空参数提示；动态模板缺少查询参数时使用该提示，留空则显示默认文案；
- `{query}` 代表关键词之后的完整参数，替换前必须使用 UTF-8 百分号编码；
- 使用 `{query}` 时，`google test codex` 会把 `test codex` 作为一个完整值，不需要写引号；
- `{query0}`、`{query1}`…代表按安全 argv 规则解析的位置参数；例如模板 `?q={query0}&v={query1}` 配合 `google test codex` 生成 `?q=test&v=codex`；
- 位置参数本身包含空格时使用引号，例如 `google "hello world" codex`；引号只用于分组，不进入 URL；
- 同一占位符可重复出现，也可混用 `{query}` 与位置参数；每次替换都独立进行 UTF-8 百分号编码；
- 占位符是可选的；URL 不含占位符时作为固定直达链接，忽略关键词后的额外参数，并允许只输入命令关键词执行；若使用占位符，未知、未闭合或超过 `{query31}` 的占位符不允许保存，位置参数模式执行时若缺少参数或分组引号未闭合，只显示错误结果且不得打开浏览器；
- 模板必须使用规范的 `https://` 或 `http://` 前缀，拒绝省略双斜杠、反斜杠形式以及 `file:`、`javascript:`、`data:` 等其他协议；
- 模板中的域名和固定路径在执行前不可由查询参数改写；
- 设置页保存前展示示例 URL，并检查 URL 能否被正确解析；
- 带占位符的模板在查询参数为空时显示用法提示；固定直达链接在只输入关键词时生成可执行结果，但仍必须由用户按 `Enter` 或点击后才能打开；
- 首版统一使用系统默认浏览器；
- URL 打开动作必须来自用户按 `Enter` 或点击结果，不能由搜索建议、预览渲染或主题文件触发；
- 网络查询会暴露给目标网站及浏览器历史，首次创建命令时应给出简短隐私提示。

可选预置模板可包含 Google、Bing、DuckDuckGo、GitHub、npm 等，但预置项也只是普通用户配置，可被重命名、禁用或删除。

### 5.7 自定义主题皮肤（P1）

搜索界面和设置界面使用两套完全独立的主题配置、内置主题、自定义主题列表和导入导出文件。编辑、重命名、删除或导入其中一侧的皮肤，不得改变另一侧。

搜索界面主题控制项：

- 强调色，以及搜索窗口背景、外层边框颜色/宽度、主题默认窗口宽度、圆角、透明度、模糊、阴影与背景图；通用设置中的显式宽度可覆盖主题默认值；
- 搜索框背景、边框颜色/宽度/样式/宽度、输入文字颜色与字号；
- 普通结果背景、主文字/次文字颜色与字号、结果行高；
- 选中结果背景、主文字/次文字颜色与字号；
- 结果图标尺寸、最大结果数，以及放大镜、Suo Logo、来源标签的显隐。

设置界面主题控制项：

- 强调色，以及设置窗口、标题栏、侧栏、内容区和卡片背景；
- 边框、主文字、次文字、侧栏普通文字、侧栏选中背景；
- 基础字号、圆角、透明度、模糊、阴影与背景图。

共同要求：

- 两个 scope 均保留午夜、纸张、森林三套只读内置皮肤；每个 scope 最多保存 12 套自己的自定义皮肤；
- 每个 scope 顶部使用“正在使用的皮肤”下拉框切换运行皮肤；皮肤库使用独立的“正在编辑的皮肤”下拉框，两者状态不得耦合；
- 编辑器工作副本只更新当前 scope 的右侧预览；无修改时保存按钮必须置灰并提示“当前皮肤没有修改”。统一保存开启时，“保存皮肤”只写入页面草稿并等待全局“保存设置”；统一保存关闭时，正在使用的皮肤显示“保存并应用”并在一次点击后持久化和生效，非正在使用的皮肤先显示“保存皮肤”，保存完成后按钮变为“应用”，由用户显式切换运行皮肤；
- 提供新建、重命名、删除、恢复默认、导入和导出；只读配置下禁止修改；
- 搜索皮肤只接受 `suo-launcher-theme-v1`，设置皮肤只接受 `suo-settings-theme-v1`；错 scope、旧 `suo-theme-v1`、不支持版本、字段缺失、未知字段和越界值均拒绝，失败不得改变当前草稿；
- 配置 v6 将 v5 及更早的统一 `appearance` 自动复制并迁移为 `launcherTheme` / `settingsTheme` 两个独立 scope；v6 文件缺少任一 scope 时拒绝加载。配置 v7 新增 `saveSettingsManually`，v6 及更早版本迁移时默认开启；配置 v8 新增空输入与非空输入防抖，旧版本迁移后分别保持 0 ms 和 50 ms；配置 v9 新增启动器宽高与位置偏移，v8 迁移后宽度继续跟随当前搜索皮肤、高度为 520 px、偏移为 0/0；配置 v10 新增 macOS Dock 图标可见性，v9 迁移后默认开启；配置 v11 新增 `globalHotkey`，v10 及更早版本按当前平台迁移为默认组合键；配置 v12 为脚本和网络搜索新增可选 `iconDataUrl` / `inputHint`，v11 及更早配置迁移后均为空并保持原结果外观与提示；配置 v13 为共用 `fy` 增加 `translation.provider`，v12 及更早迁移为 `microsoft` 并继续读取原 Microsoft 系统凭据项；配置 v14 为脚本增加 `resultAction`，v13 及更早迁移为 `copy`，不得让旧脚本在升级后自动获得 Shell 执行能力；
- 可选择本地 PNG、JPEG 或 WebP 背景图，单张原始文件最大 1.5 MB，宽高均不得超过 4096 px；背景图以内嵌 data URL 保存和导出，不加载远程 URL；Base64 必须规范，并须通过实际图片解码与资源上限检查，只有文件头、伪造或截断的数据必须拒绝；
- 文字与背景默认满足 WCAG AA；编辑器实时显示核心文字和边界对比度，可读性警告不得要求用户重复点击同一个保存按钮，也不得伪装成保存失败；透明窗口或背景图会受桌面内容影响，编辑器不得把纯色近似检查描述为最终“通过”，并需提示在真实桌面复核；
- macOS 与 Windows 可在各自 scope 中保存独立的模糊和透明度覆盖值。

## 7. UI 设计规范

### 7.1 主窗口

- 默认宽度 720 px、默认高度 520 px；宽度可在 560–1200 px、高度可在 320–720 px 内调整；
- 默认距活动屏幕顶部约 18%；水平和垂直微调都以当前默认位置为 0，超出工作区时自动夹紧；
- 搜索区高度：76 px；结果行高度：64 px（紧凑模式 52 px）；
- 默认保持完整窗口并显示空状态；可选开启空输入紧凑模式，此时原生窗口收起到 74 px 搜索区，开始输入后恢复完整高度；
- 搜索框不显示传统矩形边框，使用容器分隔线建立层级；
- 选中项只使用强调色半透明背景与边框，不额外叠加左侧指示条；
- 底部仅展示当前可用快捷键，降低视觉噪音。

### 7.2 设置中心

- “命令与服务”使用“脚本命令 / 网络搜索 / 服务”页内分段切换；
- 每项默认显示约 70 px 高的摘要卡片，包括启用状态、名称、关键词、单行描述和关键标签；
- 每项末尾提供无分隔线的独立启用开关；开启时轨道为绿色，关闭时保持灰色；
- 点击摘要后原地展开编辑，同一时间只展开一项；切换项目或分类时将当前修改写入页面草稿；
- 设置页右上角提供“统一保存设置”开关：开启时普通修改与“完成编辑”只更新页面草稿，必须点击“保存设置”统一校验并持久化；关闭时合法的普通修改自动保存，脚本、网络搜索和服务在“完成编辑”后保存；
- “取消”丢弃当前项尚未提交的修改；翻译 API 密钥仍由系统凭据按钮独立即时保存，不进入 JSON 草稿；
- 通用设置显示当前 `config.json` 完整路径，提供“打开文件夹”“更改位置”和自定义位置下的“恢复默认”。目录选择使用系统原生选择器；目标已有 `config.json` 或 `.bak` 时必须拒绝覆盖；
- macOS 默认路径为 `~/Library/Application Support/io.github.dqgod.suo/config.json`，Windows 默认路径为 `%APPDATA%\io.github.dqgod.suo\config.json`。自定义位置由默认目录内固定的版本化 `config-location.json` 指针发现；迁移顺序必须是目标配置写入并校验成功、位置指针原子更新、运行时路径切换，任一步失败都继续使用原路径；
- 配置位置迁移只复制普通 JSON 配置，原位置文件保留为恢复副本；系统凭据库中的翻译密钥不移动、不导出；
- 新增项直接进入展开编辑状态；取消新增时移除该草稿；删除已有项前必须确认；
- 描述为可选字段，最多 200 个字符；为空时摘要显示“暂无说明”。
- 脚本命令和网络搜索编辑器提供可选图标与空参数提示：图标只通过系统文件选择器读取本地 PNG/JPEG/WebP，最大 256 KB、宽高均不超过 512 px，并以内嵌 data URL 保存；拒绝远程 URL、伪造、截断或无法解码的文件。提示最多 160 个字符。脚本编辑器另提供“返回值动作”，默认复制；选择执行 Shell 时必须持续显示平台和风险说明。

### 7.3 状态设计

必须覆盖：

- 初始/最近使用；
- 正在搜索；
- 有结果；
- 无结果；
- 计算结果；
- 命令缺少参数；
- 脚本运行中、成功、超时、退出码非零；
- 翻译加载、成功、失败；
- 索引暂停或权限不足。

### 7.4 无障碍

- 全流程可键盘操作；
- 支持系统减少动态效果；
- 不只用颜色表达状态；
- 屏幕阅读器可读出结果数、选中项、类型和动作；
- 缩放至 200% 时主操作仍可用；
- 支持高对比度主题。

## 8. 推荐技术架构

### 8.1 技术选型

推荐：**Tauri 2 + Rust 核心 + TypeScript/React UI + SQLite**。

选择理由：

- Tauri 适合常驻型轻量桌面应用，安装包和空闲资源通常比捆绑完整 Chromium 的方案更可控；
- Rust 适合实现热键、索引、模糊匹配、进程管理和平台适配等本地能力；
- Web UI 便于主题变量化、快速迭代设置中心；
- SQLite FTS5 适合本地限定目录索引、使用频率和缓存；
- 前后端通过明确命令协议交互，脚本进程不直接接触 UI WebView。

备选方案：Flutter。它能提供高度一致的跨平台渲染，但脚本宿主、系统索引、应用发现仍需分别编写原生插件。若团队更熟悉 Dart，可选 Flutter，但不要把“跨平台 UI”误认为“系统集成无需适配”。

### 8.2 模块划分

```text
Suo UI (React/TypeScript)
        │ typed IPC
        ▼
Query Orchestrator (Rust)
  ├─ Command Router
  ├─ Result Ranker
  ├─ Calculator Provider
  ├─ Translation Provider
  ├─ Web Search Provider
  ├─ App Provider
  ├─ File Provider
  └─ Script Runner
        │
        ├─ SQLite / secure credential store
        ├─ macOS adapter: hotkey, apps, metadata, open/reveal
        └─ Windows adapter: hotkey, apps, search, open/reveal
```

关键原则：每个 Provider 接收同一查询上下文，并流式返回结果。Orchestrator 对旧查询使用递增 query ID 取消或丢弃结果，避免“较慢旧请求覆盖较新输入”。

### 8.3 Provider 接口建议

```ts
type QueryContext = {
  queryId: number;
  rawText: string;
  normalizedText: string;
  tokens: string[];
  signal: AbortSignal;
};

type ResultItem = {
  id: string;
  provider: "app" | "file" | "calculator" | "translation" | "web-search" | "script";
  title: string;
  subtitle?: string;
  icon?: string;
  score: number;
  primaryAction: Action;
  secondaryActions?: Action[];
};
```

## 9. 本地数据与隐私

建议数据分类：

| 数据 | 存储方式 | 默认保留 |
| --- | --- | --- |
| 应用/文件索引 | SQLite | 持续，直到目录移除或重建 |
| 使用频率 | SQLite 聚合计数 | 持续，可一键清除 |
| 查询历史 | 默认关闭 | 用户开启后按上限滚动 |
| 脚本配置 | JSON/SQLite | 持续 |
| API Key | macOS Keychain / Windows Credential Manager | 持续 |
| 运行日志 | 滚动日志 | 默认 7 天或 20 MB |
| 翻译缓存 | 默认仅内存；用户可开启有容量和期限限制的 SQLite 缓存 | 退出即清除或按用户配置 |
| 网络搜索查询 | Suo 默认不保存；目标网站与浏览器按各自策略处理 | 不适用 |

隐私原则：本地查询不上传；只有翻译等明确的联网 Provider 可以发送必要文本。首次启用在线翻译时展示数据流向说明。

## 10. 错误处理与诊断

- 全局快捷键注册失败：显示冲突说明并直接打开快捷键录制；
- 文件权限不足：指出具体目录并提供系统授权引导；
- 原生索引不可用：自动降级并展示当前搜索范围；
- 解释器未找到：展示当前解析路径和“选择解释器”；
- 脚本退出非零：主结果显示简短错误，诊断页提供退出码和截断后的 stderr；
- 翻译失败：区分网络、鉴权、限流、服务端和取消；
- 网络搜索模板无效：指出协议、占位符或 URL 解析错误，禁止执行；
- 数据库损坏：先备份损坏文件，再重建可再生索引，不直接删除用户命令配置。

设置页提供“复制诊断信息”，默认对用户目录、参数、Token 和 API Key 脱敏。

## 12. MVP 验收标准

### 快捷键与窗口

- macOS 和 Windows 默认快捷键可配置，并能识别注册冲突；
- 正常运行环境下连续启动应用两次时仅保留一个 Suo 进程，已有主窗口被唤醒并聚焦；
- 系统托盘图标在主窗口隐藏时仍然可见；macOS 模板图标可随菜单栏明暗反色且没有彩色方形底，右键菜单的显示、设置和退出操作均可用；macOS 开关开启时仅在设置窗口打开期间显示 Dock 图标，设置关闭后自动隐藏，开关关闭时始终隐藏，实时关闭开关不得关闭或隐藏设置窗口；菜单栏入口、全局快捷键及后台进程始终可用。Windows 搜索窗口显隐时均不创建任务栏入口，设置窗口打开后必须显示彩色任务栏图标；
- 100 次连续唤起/关闭不丢失输入焦点、不出现多个窗口；
- 冷启动后的第一次快捷键直接在最终尺寸与位置显示，不出现默认居中窗口闪烁；macOS 设置窗口位于后台时，第二次快捷键隐藏搜索框后仍回到原外部应用；
- 开启空输入紧凑模式后，空查询仅显示搜索框且不存在透明点击区域；输入、清空时窗口能稳定展开和收起；
- 空输入与非空输入防抖可分别保存 0–60000 ms；默认值为 0 / 50 ms，连续输入只执行尾沿查询，即时脚本继续使用自己的逐项配置；
- 启动器宽高和水平/垂直偏移的上下限由前后端共同校验；0/0 偏移保持原始唤起位置，极值设置不会让窗口离开目标显示器工作区；
- 多显示器策略与设置一致。

### 搜索

- 新安装/卸载应用能在增量扫描后正确出现/消失；
- 默认目录中的新增、重命名、删除文件能同步到结果；
- 10 万条限定目录索引下，常见查询 P95 首屏结果不超过 200 ms；
- 打开、显示所在位置、复制路径均可用。

### 配置与数据位置

- 首次启动显示平台默认配置路径；点击“打开文件夹”后由 Finder / Explorer 打开当前目录；
- 选择空目录后，当前配置完整复制到目标 `config.json`，设置页立即显示新路径，后续保存写入新位置，重启后仍从新位置读取；
- 目标目录已有 `config.json` 或 `.bak`、目标不可写、位置指针写入失败或存在更新版本配置时，迁移失败且当前运行路径不变；
- 恢复默认位置后，当前配置写回默认路径并更新指针；此前自定义位置的文件仍保留；
- 自定义目录临时不可用时给出明确警告并回退默认配置位置，不静默覆盖或删除任一配置；
- 配置迁移前后的普通 JSON 均不包含 Keychain / Credential Manager 中的 API 密钥。

### 计算与翻译

- `11+1` 返回 `12`；除零、语法错误、超长表达式有明确处理；
- `fy hello` 能显示译文；快速连续输入不会展示旧请求结果；
- 设置页可在 Microsoft、Google 与有道之间切换当前 `fy` Provider；摘要和结果区显示实际 Provider，未配置当前 Provider 凭据时给出设置入口；
- 凭据不出现在普通配置、日志和诊断导出中。

### 网络搜索

- `google codex` 显示可执行结果，按 `Enter` 打开 `https://www.google.com.hk/search?q=codex`；
- 配置 Google 图标和自定义空参数提示后，提示结果与可执行结果均显示该图标；删除图标后恢复内置网络图标；
- `google codex launcher` 中的空格被编码，中文、`&`、`?`、`#` 等字符不会改变模板结构；
- 模板 `?q={query0}&v={query1}` 配合 `google test codex` 分别编码两个参数；`{query}` 模式下同一输入仍作为无需引号的完整参数；
- 空参数不会打开浏览器；`javascript:`、`file:`、`data:` 等模板无法保存；
- 只输入建议或切换选中项不会产生外部跳转；

### 脚本

- `ts 1786082576069` 将时间戳作为单个 argv 参数传递并展示脚本输出；
- Enter 执行脚本配置图标后，动作结果和输出结果均使用该图标；只输入关键词时可显示自定义提示，但零参数仍保持可执行；
- `ts 1786082576069 +8` 将两个 argv 参数传给示例脚本，由脚本将第二项解释为时区偏移；
- v13 及更早脚本配置迁移后 `resultAction=copy`；`ts` 的既有复制行为保持不变；
- 将 `open_file` 配置为 `examples/open_path.py` 且 `resultAction=executeShell` 后，第一次 Enter 只显示返回命令，第二次 Enter 才在 macOS Bash / Windows PowerShell 执行；同一结果不可执行两次，查询或配置变化后不可再执行；
- 空返回、NUL、超过 16 KiB、超时、失败退出和取消均不得留下可执行授权；WebView 篡改 action ID 不得执行任意命令；
- 即时脚本可配置 20–60000 ms 输入停顿延迟，低于 20 ms 的配置无法保存；
- 带空格、引号和 shell 元字符的参数不会在 argv 模式下被二次解释；
- 超时能终止进程树；输出超限时安全截断；
- 未找到解释器、脚本无权限、退出码非零均有可操作提示；
- 设置页可打开脚本所在文件夹，并在 Finder/Explorer 中选中实际解析后的脚本文件；
- 修改脚本文件后再次运行会触发重新确认。

### 主题

- 搜索皮肤和设置皮肤拥有独立主题列表；修改、删除、导入或保存一侧不会改变另一侧；
- 搜索皮肤的窗口/搜索框边框、输入文字、普通/选中结果颜色和字号、图标尺寸与放大镜/Logo 显隐均能反映到预览及实际搜索窗口；
- 设置皮肤只改变设置窗口的标题栏、侧栏、内容区、卡片和文字，不污染搜索窗口 token；
- `suo-launcher-theme-v1` 与 `suo-settings-theme-v1` 不能跨 scope 导入；非法主题文件无法导入且不影响当前主题；
- 深浅主题和高对比模式下核心文字可读；纸张主题的快捷键标签文字与背景满足可读对比度。

## 13. 主要风险与决策建议

| 风险 | 影响 | 建议 |
| --- | --- | --- |
| macOS `Command + Space` 与 Spotlight 冲突 | 首次体验受阻 | 首次启动检测；一键录制替代快捷键；提供系统设置说明 |
| Windows `Alt + Space` 覆盖窗口菜单 | 与既有习惯冲突 | 明确提示，可通过录制按钮改为 `Alt + Q` 等组合，注册失败时保留旧快捷键 |
| 两个平台文件索引能力不一致 | 搜索结果和性能不一致 | Provider 抽象 + 限定目录自有索引回退；不承诺全盘一致性 |
| 用户脚本及 `executeShell` 返回动作等同于本机代码执行 | 安全和信任风险 | 仅运行用户显式添加的本地脚本；默认复制和 argv；Shell 动作逐项高风险提示、二次激活、一次性后端授权、无提权 |
| 在线翻译涉及文本外发 | 隐私风险 | 明确提供方、最小发送、默认不记历史、凭据安全存储 |
| 主题透明/模糊跨平台差异 | 视觉不一致 | 允许平台覆盖值，以可读性优先，不追求像素级一致 |

## 14. 推荐的首版产品决策

为保证首版可以按时交付，建议直接锁定以下决策：

1. 使用 Tauri 2 + Rust + React/TypeScript + SQLite；
2. 文件搜索只做文件名/路径；普通查询覆盖常用用户目录，`f` 命令搜索全盘系统索引；
3. Windows 优先已有 Everything，安装版可启用内置实例，失败时回退到手动重建的限定目录索引；macOS 使用 Spotlight；
4. 自定义脚本支持 Python、Bash、PowerShell 和可执行文件；默认安全 argv，同时提供显式 Shell 高级模式；
5. 脚本同时支持纯文本和 UTF-8 `suo-json-v1`，并可配置即时或回车执行；
6. 翻译内置 Microsoft Translator、Google Cloud Translation Basic 和有道智云文本翻译，三者共用 `fy` 与目标语言规则；不开放任意 REST 翻译编辑器；
7. 网络搜索支持固定直达 URL、整段 `{query}` 与 `{query0}`、`{query1}`…位置参数，URL 仅限 HTTP/HTTPS，统一使用默认浏览器；
8. 搜索界面与设置界面各自默认午夜皮肤，分别保留午夜、纸张、森林三套内置皮肤，并提供受固定字段约束的独立自定义皮肤编辑器及 `suo-launcher-theme-v1` / `suo-settings-theme-v1` JSON 导入导出；
9. 本地优先，不做账号、插件市场、远程脚本、自动遥测和自动更新。

这组边界既能完整覆盖“搜索、计算、翻译、脚本、换肤”的核心承诺，也避免 MVP 被插件生态、全盘索引和跨设备同步拖慢。
